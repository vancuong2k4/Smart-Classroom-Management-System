## Cấu trúc chuẩn của một file README_TXXX.md
1. **Bảng thông tin** — Task ID, Stream, Epic, Người phụ trách, Trạng thái, Definition of Done
2. **Mục tiêu**
3. **Những gì đã làm** / file tạo mới & sửa đổi
4. **Cách chạy / Cách sử dụng** (API, lệnh...)
5. **Quyết định kỹ thuật** và lý do
6. **Kết quả kiểm thử**
7. **⚠️ Lưu ý & Việc còn tồn đọng** (checklist)
